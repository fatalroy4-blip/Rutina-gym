# Mi Rutina Gym · fotografías

Abre index.html junto con la carpeta assets. No necesita instalación ni proceso de compilación.

## GitHub y Vercel

1. Descomprime este paquete.
2. Copia index.html, assets, FUENTES-IMAGENES.md y FUENTES-IMAGENES.json a la raíz del repositorio, sustituyendo index.html. Conserva otros archivos que ya necesite tu proyecto.
3. En Vercel usa el proyecto existente. Si creas uno: Framework Preset Other, sin Build Command y directorio de salida raíz (.).

## Progreso existente

La clave de almacenamiento sigue siendo rutina-progresiva-6-dias:v2. Los IDs, las rutinas A/B, las tres series, los pesos, las alarmas y los cronómetros conservan su lógica original. Los registros siguen en el navegador y dominio donde entrenaste. Publicar en otro dominio o abrir index.html como archivo no transfiere esos registros: exporta el progreso desde la página anterior e impórtalo cuando cambies de dirección.

## Imágenes

38/38 fichas tienen una imagen de referencia. Se incluyen 24 fotografías reutilizables y las siete imágenes aportadas por el usuario; algunas imágenes del mismo aparato se comparten entre variantes. Las diferencias de ejercicio están señaladas. Ninguna foto se afirma como el modelo exacto del gimnasio. Consulta FUENTES-IMAGENES.md para fuentes, licencias y variantes.

## Visor

Abre cualquier fotografía desde la rutina o el catálogo. Puedes pellizcar, arrastrar, usar los botones +/− o la rueda del ratón y restablecer. Escape o Cerrar regresa al entrenamiento; los cronómetros continúan.
